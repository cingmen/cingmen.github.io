01 / About

Security is not a product — it is a mindset. You cannot defend what you have never tried to break.

I work with an offense-first philosophy: model the adversary, chain the small failures, and translate every exploit into a durable control. Red teaming sharpens blue teaming — each finding is written so an engineer can act on it, not just admire it.

My work spans external infrastructure assessments, web application testing, detection engineering and long-form vulnerability research.
